### 2. 검색 조건 저장 (#1)

- 처음엔 "저장 안 됨" 버그 신고였지만 **아직 없던 기능**이었다 (개발계획서 메뉴에만 있음). 사용자 선택: 이름 붙여 저장 + 마지막 조건 자동 기억 둘 다.

### 3. 개찰 결과 (#1, #3)

- data.go.kr **낙찰정보서비스**는 같은 키로 이미 쓸 수 있었다. 경로는 `/1230000/as/ScsbidInfoService/` (구 경로 400).
- 실제 호출로 확인한 것: 개찰 목록 `inqryDiv=1`(개찰일시, 하루 약 340건), 1순위는 `opengCorpInfo` 한 칸에 `^`로, 업체별 순위 `inqryDiv=4`(참가 3천 곳 넘는 공고도 있음), **하한 미달·예가 초과·취소 업체는 `opengRank`가 빈 값**, 예비가격 15줄에 같은 `plnprc`(예정가격)·`bssamt`.
- 개찰 목록은 수집마다 받고(처음엔 백필 기간만큼), 업체별 순위·예정가격은 호출이 많아 **상세 화면을 열 때와 내 투찰·관심 공고(수집마다 10건)** 만 받는다.
- 첫 수집: 2,373건 받아 저장된 공고 2,359건에 붙임.
- 계산: 실제 사정률 = 예정가격 ÷ 기초금액, 낙찰하한 금액 = (예정가격 − A값) × 하한율 + A값, 업체 사정률은 투찰금액을 계산기 산식으로 역산.
- 내 순위 = 순위 있는 업체 중 나보다 낮게 쓴 곳 + 1. 하한 미달·예가 초과는 따로 표시.
- **실제 화면 확인 (#3)**: 참가 802곳 공고에 확인용 투찰 기록 → 상세·내 투찰 기록 모두 "4순위 (추정)", 1순위와 차이 +0.0068%p. 마감된 공고는 화면에서 기록을 못 넣게 돼 있어 DB에 임시로 넣고 확인 뒤 지웠다.
- **실패 구간 재수집 (#3)**: 개찰 결과 성공 시각을 `CollectorSetting.ResultsLastSuccessTo`로 공고와 따로 기록. 실패하면 다음 수집 때 거기서부터 (최대 60일). 규칙은 `CollectorRules.ResultsFrom`.

### 4. 회사·면허 정보, 내 면허로 참여 가능 (#2)

- 기획 문서에는 "면허·실적·시공능력으로 참여 가능 금액대" 목표만 있고 산식은 없었다. 사용자와 정한 순서: 1단계 면허, 2단계 금액.
- **면허 그룹 해석을 바로잡았다 (중요).** 기존 코드·화면은 "그룹 안 = 또는, 그룹끼리 = 그리고"였는데 실데이터(면허 제한 12,353줄)를 보니 반대였다.
  - **같은 `lmtGrpNo` 안은 그리고(모두 필요), 그룹끼리는 또는(한 그룹만 갖추면 됨).**
  - 예) 그룹1 토목건축공사업 / 그룹2 건축공사업 → 둘 중 하나. 한 그룹에 일반소방(전기)+일반소방(기계) → 둘 다.
- 원문 `permsnIndstrytyList`(그 줄 대신 인정하는 업종, 예: 건축공사업 줄에 토목건축공사업)가 줄의 약 24%(2,976줄)에 있는데 저장하지 않고 있었다 → `NoticeLicense.Alternatives`에 저장, 기존 데이터는 시작할 때 원문에서 한 번 채움.
- 판정 규칙은 `LicenseEligibility` 한 곳. 목록 필터도 SQL로 옮기지 않고 같은 규칙을 쓴다.
- `/me`: 회사 정보, 보유 면허(진행 공고에 나온 이름에서 고르기). 메인 필터 `mine=true`, 상세에 판정 표시.
- 주력분야(`indstrytyMfrcFldList`)·지역 제한은 아직 판정하지 않는다.

### 5. 입찰 가능 금액 2단계 (#4)

- 추정가격(`presmptPrce`)을 `Notice.EstimatedPrice`로 저장, 기존 공고는 마이그레이션 SQL로 원문에서 채움.
- 면허별 시공능력평가액·최근 실적 합계·실적 배수 (`/me`에서 억 원 단위 입력).
- 금액 상한 = min(시공능력평가액, 실적 ÷ 배수), 넣은 값만으로 계산 (`LicenseEligibility.AmountLimit`).
- 그룹 안 여러 면허 → 가장 작은 상한, 여러 그룹 충족 → 가장 넉넉한 그룹, 대체 업종으로 충족하면 그 면허의 상한.
- 추정가격 > 상한이면 "금액 상한 초과"로 따로 세고 `mine=true`에서 뺀다. 상한이나 추정가격을 모르면 면허만 본다.
- 실적 배수는 발주처·금액대마다 달라 지금은 직접 입력 (실적 배수 표가 정리되면 자동으로).
